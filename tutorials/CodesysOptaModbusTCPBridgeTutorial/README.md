# How to Configure a Modbus TCP Bridge with Finder OPTA in CODESYS

This tutorial shows how to configure the Finder OPTA as a Modbus TCP bridge in
CODESYS, receiving coil commands from a PC as a server and forwarding them as a
client to a second Finder OPTA acting as a Modbus TCP server, so that the LEDs on
both devices follow the same commands.
