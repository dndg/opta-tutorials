# How to configure a Modbus TCP Client with Finder OPTA in CODESYS

This tutorial shows how to configure the Finder OPTA as a Modbus TCP client in
CODESYS, reading an Input Register exposed by a second Finder OPTA acting as a
Modbus TCP server and using the value read to drive the LEDs of the device.
